# Catálogos de trabalho — LG ThinQ AirCon Widget

`templates/` contém os templates extraídos das fontes QML/Python. `en/` e `pt_BR/`
contêm POs sem traduções revisadas; as entradas estão vazias. Os quatro MOs
selecionados contêm cabeçalho e usam fallback para a redação-fonte atual, mista.
Não se atribuiu tradutor, titular ou licença por inferência.

O domínio Python legado é mantido por compatibilidade. Para extração, compilação,
revisão e seleção exata dos pacotes, veja [internacionalização](../docs/I18N.md).
Traduções sintéticas pertencem somente aos testes, nunca aos catálogos do produto.
